## 決めたこと・ずれ

1. change-apply.md の戻し方の文（5の `revert`、7の5）は変えていない。scaffold の組の今の `undo_command`（`git -C <P> revert --no-commit <直したコミット> && git -C <P> commit -m "…" -- .`）でも、返す項目の名前は `revert` のままで、「直す前に戻すコマンド」の言い方も合っているためである。
2. change-start.md の7（「6の返り値に、これからの流れの文があれば…」）は持ち物でないので変えていない。並びを変えても文のとおりで正しい。better_fix の「返り値の1行目を指す」に直すかは、持ち主の組に任せる。
3. （2回目の点検で変えた）worker.agent.md の D の新しい項の「（変えないと書かれていても）」は消した。change-apply.md の2（40行「変えない差し込み口とファイルの一覧（書き換えない）」）と食い違い、文書の差し込み口と `files/docs/` は、もう change-apply.md の2で変える一覧に入るためである。変えないと書かれたものに食い違う文があれば、変えずに「足りなかったこと」に書かせる。
