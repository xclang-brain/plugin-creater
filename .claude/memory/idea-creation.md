# アイデア創出（6つの柱）

開発者が示した、AI でアイデアを作るときの考え方（2026年10月）。アイデア創出スキル（make-idea）の中心である。

## 6つの柱

- アイデア創出の本質は、次の6つにまとめられる。開発者は「無限にある情報の中で、アイデア創出の本質はこの6個に絞られる。これが本質を見極めるということ」と言った。
  1. 制限の決定
  2. 徹底的な事前調査
  3. 本質の見極め（なぜなぜ分析）
  4. 本質の掛け合わせによるアイデア創出（壁打ち）
  5. アイデアの説明（第三者目線）
  6. 知識・経験の蓄積
- この6つを「6つの柱」と呼ぶ。名前・順番・中身は、開発者の承認なしに変えない。変えたほうがよいと考えたら、変えずに案を出す（憲章 第26条）。
- 調べた研究や公開の手法は、柱を実現するやり方と落とし穴の対策にだけ使う。7つ目の柱や別の枠組みを持ち込まない。

## 柱の中身で、開発者がはっきり言ったこと

- 本質は、たくさん用意してから選ぶ。掛け合わせるのは一度に2〜4個でよいが、その前の本質の見極めで2〜3個だけを作るのではない。
  - 例：本質の山から使えそうな3つを選んで掛け合わせ、壁打ちする。だめなら別の3つ、さらに別の3つ。それでもだめなら4つや2つにする。
- なぜなぜ分析、壁打ちの相手、説明を読む第三者は、どれも2者以上のエージェントで行う。壁打ちと説明は、作った本人ではない相手に見せる。
- 事前調査は、速くするために複数のエージェントで並列に行う。
- 柱の中の数は、すべてパラメーターにし、ファイルで変えられるようにする（憲章 第27条）。初期値は、事前調査100件以上、本質30個以上、なぜなぜ分析のエージェント2以上、掛け合わせる本質2〜4、壁打ちの相手2以上、説明の読み手2以上。

## 知識・経験の蓄積は、洗練して残す

- 優れた発明家は、事前調査の情報だけでなく、自分の過去の経験と知識からアイデアを作る。だから、作業を終えたら振り返り、知識・経験として残す。
- 残すのは、事前調査で学んだこと、気づいたこと、うまくいったこと、失敗したことなど、あらゆること。
- ただし、ログのように全部を残さない。本質を見極め、洗練した形で残す。大量にあっても洗練されていなければ、探すのに時間がかかるためである。
- 残した知識・経験は、次の回の6つの柱すべてで使う。
- 研究でも、記録を丸ごと足すより、要点を短くして出典を添えた方が効いた例が多い。一方で、全体を書き直すと細部が消える（ACE の context collapse）。項目の単位で足し・直し・消し、具体例と出典を添える。
