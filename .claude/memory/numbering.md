# 憲章の条・要件（REQ）・版の番号

- 憲章の条と要件（REQ）は、すべての文書を通した通し番号で、仕様書・設計書・テストの名前から番号で参照される。条を途中に入れて繰り下げると、憲章の外の多くの箇所を直すことになる（アイデア創出の計画の見積もりで約60か所）。新しい条は後ろに足す。
- ただし、長いセッションの間に main 側も後ろに足すと、条番号・REQ 番号・版がぶつかる。2026年10月、このブランチは第25〜27条・REQ-052〜065・版 0.26.0 を足したが、その間に main が第25条（部品の独立性）・REQ-052〜062・版 0.27.0 を足していた。取り込みで、こちらを第26〜28条・REQ-063〜076・0.28.0 に付け直した。
- 番号や版を付ける前と PR を作る前に、origin/main を取り込み、空いている番号と版を確かめる。
- 付け直すときは、本文の参照だけでなく、テストの関数名（`test_REQ_062_…` など）、設計書の表の範囲、憲章の用語の表（第3条）の参照も直す。取り込みの後の見直しで、これらの直し漏れが見つかった。
