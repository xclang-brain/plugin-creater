# GitHub Copilot CLI と Claude Code で使えるプラグインの制限

アイデア創出スキル（make-idea）の2回目の試行に使う制限。開発者が示した「GitHub Copilot CLI と Claude Code で使えるプラグイン」という制限だけを、頼みの文（`request.txt`）と、ユーザー役が知っていること（`restriction.md`）にした（2026-10-28）。制限は事前調査の取っかかりで、できたアイデアがこの範囲から外れてもよい（[アイデア創出の要件](../../../../docs/specs/idea-requirements.md) 1章）。動かし方は `tests/dev-eval/runner/idea.mjs` の冒頭にある。
