# 柱3 本質の見極め（なぜなぜ分析）

目的：掘り下げた作品に「なぜ評価されているのか」「なぜこの形なのか」を重ね、表面の特徴の奥にある本質を、たくさん用意する。一人で完結させず、複数のエージェントが互いの分析に意見を出し合って磨く。

## 本質の形

- 本質は、目的（何のためか。誰の何の困りごとを解くか）と仕組み（どうやってそれを満たすか）で書く。
- 裏づけの作品の番号と、引用（README、レビューなど）を付ける。引用がないものは「仮説」と印を付ける。
- 目的と仕組みで書けないもの（例：使い心地）は、「形の外」と印を付けて残す。
- ほかの本質の言い換えは、別の本質として数えない。1つの本質を細かく割って数を増やさない。

## 手順

### 1. 独立の分析

- `knowledge/3-essence.md` を読み、使う項目を決める。過去の本質は、今回の作品で裏づけ直せたものだけを使う候補にする。
- 分析の観点を、「なぜなぜ分析をするエージェントの数」だけ決める。観点は互いに違うものにする。例：使う人の困りごと、仕組みと作り、広まり方と使われ方、制限との関係。
- `plugin-creator:idea-thinker` を、観点ごとに1体、1つの応答で同時に起動する。頼みの文には次を書く。
  - 役：なぜなぜ分析
  - 自分の観点
  - 読むファイル：`<回のフォルダ>/restriction.md`、`<回のフォルダ>/research/deep-*.md`（すべて）、`<回のフォルダ>/research/index.md`
  - やり方：作品ごとに「なぜ評価されているのか」「なぜこの形なのか」を問い、答えに「それはなぜか」を重ねる。段の上限は、なぜを重ねる段の上限の数。各段に根拠（引用か作品の番号）を付ける。たどり着いた本質を、上の「本質の形」で書く。本質は、本質の数以上出す。
  - 使う知識・経験の項目（過去の本質の候補、役に立った問い方）
  - 書くファイル：`<回のフォルダ>/essence/analysis-<a>.md`（a はエージェントの番号）。20,000 バイト未満にする。
  - 返事：出した本質の数だけ。
- このとき、ほかのエージェントのファイルの場所は渡さない。互いを見ずに分析させるためである。

### 2. 意見の出し合い（往復の数だけ繰り返す）

- 各エージェント a に、`plugin-creator:idea-thinker` を1体ずつ、同時に起動する。頼みの文には次を書く。
  - 役：ほかの分析への意見
  - 読むファイル：自分（a）の前の版の分析と、ほかのエージェントの前の版の分析（1回目は `analysis-*.md`、2回目からは前の回の `final-*.md`）
  - やり方：ほかの分析の主な主張を、まずいちばん強い形で言い直す。そのあと、根拠の弱いところ、言い換えにすぎない本質、見落とした本質、抽象的すぎる本質（例：「便利にする」）を、相手ごとに書く。
  - 書くファイル：`<回のフォルダ>/essence/opinion-<a>-r<k>.md`（k は何回目か）
- 次に、各エージェント a に、`plugin-creator:idea-thinker` を1体ずつ、同時に起動する。頼みの文には次を書く。
  - 役：本質の出し直し
  - 読むファイル：自分の前の版の分析、ほかのエージェントが書いた意見のファイル（`opinion-*-r<k>.md` のうち、自分あての部分）
  - やり方：意見を受けて、自分の本質を直し、足し、外して出し直す。ほかのエージェントの出し直しの結果は見ない。同調しないためである。
  - 書くファイル：`<回のフォルダ>/essence/final-<a>.md`
  - 返事：出し直した本質の数だけ。

### 3. 集約

- `plugin-creator:idea-thinker` を1体起動する。頼みの文には次を書く。
  - 役：本質の集約
  - 読むファイル：`<回のフォルダ>/essence/final-*.md`（すべて）、`<回のフォルダ>/restriction.md`
  - やり方：言い換えを1つにまとめ、支持したエージェントの数を数える。議論の最後の合意ではなく、各エージェントが出し直した本質を集める。
  - 書くファイル：`<回のフォルダ>/essence/index.md`。1つの本質に、番号（E1、E2…）、目的、仕組み、裏づけの作品の番号、支持したエージェントの数、印（仮説、形の外）。20,000 バイト未満にする。
  - 返事：本質の数だけ。
- 本質の数が、パラメーターの本質の数より少なければ、`ask_user` で進め方を聞く（決める問い）。選択肢は「作品を足して続ける（おすすめ）」「今の数で進む」。おすすめの理由は「本質が多いほど、掛け合わせの組を選び直せる」。作品を足すときは、柱2の2〜4を足りない分だけ行い、この柱の1からやり直す。

### 4. 終わり

- 本質の数と、`essence/index.md` の場所をチャットに示す。
- `knowledge-used.md` の「## 柱3」に、使った項目の番号と変えた判断を書く（なければ「なし」）。
- `state.md` を「今の柱：4 本質の掛け合わせ」にし、`references/combine.md` を読む。
