# 段階「画面」

目的：できあがるプラグインの作業の画面で、開始前に設定したいこと、実行中に見たいこと、終わった後に見たい結果と見せ方を決める。

## どの作業の画面にも最初からあるもの

聞く前に、次のものは最初から画面にあると短く伝える。同じものを頼まれないようにするためである。

- 開始前：役割（まとめ役・作業役・確認役の AI）ごとのモデル、AI ごとの思考の深さ、繰り返しの上限の回数（計画・実行・評価を最大で何回繰り返すか）
- 実行中：各 AI の状態と担当、今が計画・実行・評価のどれか、AI の間のデータの受け渡しの図、止めるボタン
- 終わった後：各 AI の結果、合格の条件ごとの合否と指摘、全体のまとめ、終わった理由、見つかった課題（直したほうがよいところと、その Issue の案）

## 問い

次の3つを、1つずつ聞き出す（聞き出す問い）。

| 項目 | 問いの例 |
| --- | --- |
| 開始前に設定したいこと | 「毎回変わる値が分からないと、AI はいつも同じ条件でしか作業できません。できあがるプラグインの作業の画面で、作業を始める前に毎回決めたいことは何ですか？」 |
| 実行中に見たいこと | 「見たいことが分からないと、AI は途中の様子を画面に出せません。AI が作業している間に、できあがるプラグインの作業の画面で見たいことは何ですか？」 |
| 終わった後に見たい結果と見せ方 | 「何を見たいかが分からないと、結果を確かめにくい画面になります。作業が終わった後に、できあがるプラグインの作業の画面で見たい結果は何ですか？」 |

## 部品を決める

答えの1つずつを、用意した部品のどれで出すかを決める。部品の候補が2つ以上あるときは、決める問いで決める。候補が1つなら、それにする。

| 使う場面 | 用意した部品 |
| --- | --- |
| 開始前の設定 | 文字の入力欄、数の入力欄、選ぶ欄、チェックの欄、ファイルやフォルダの場所の入力欄 |
| 実行中と終わった後の表示 | 値の一覧、表、進み具合、文章、画像、ファイルへのリンク |

- 表示は、実行中に出すか、終わった後に出すか、両方かも決める。
- 用意のない表示を望まれたら、近い部品を示す（例：グラフは、AI が画像のファイルとして作って画像で見せる）。
- 決める問いの例：「〇〇は、入れ方によって間違いやすさが変わります。〇〇を、どの欄で入れますか？」選択肢は「選ぶ欄（おすすめ）」「文字の入力欄」のようにし、理由を1文添える。

## 記録

- `plugin-creator_progress` で、3つの項目をそれぞれ「聞いた」か「決まりなし」（何もない、と答えたとき）にする。
- 抜き書きには、決めたことが分かるユーザーの言葉を、1つの答えの中からそのまま入れる（例：「〇〇を毎回選ぶ」）。部品の名前など、ほかの答えや自分の言葉を足さない。抜き書きは、ユーザーの答えの中にある言葉かで確かめられるためである。
- 画面の設定と表示はナレッジの欄に入らない。決めた部品は、決める問いの答えとして問答の記録に残り、生成前の確認で作業の定義の案に入る。
- ほかの項目の決まりが話に出たら、ナレッジとして記録する（出どころは本文の「記録のしかた」の決め方）。
